# Scripts

This directory is reserved for reusable standalone analysis code extracted from the project notebook as the workflow matures.

At present, the primary analysis is maintained in `notebooks/BIOT670I_Microbiome_Project.ipynb`, with a Python export available as `notebooks/biot670i_microbiome_project.py`. No separate script is required simply to populate this directory.

Future reusable modules may include simulation utilities, differential-abundance wrappers, evaluation metrics, plotting functions, or Phase 3 data-processing code.
